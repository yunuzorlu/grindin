# grindin

**Show up. Every day.**  
Because 1 > 0.

grindin is a discipline-first habit and sprint tracker.  
Not a gamified productivity toy. Not motivational fluff.  
You either show up — or you don’t.

## Philosophy

- **1 > 0**  
  Doing the minimum still beats doing nothing.
- **No mercy for excuses**  
  If you miss a day, it stays missed.
- **Partial progress is still progress**  
  One completed task saves the day — but systems remember what you failed.

## Core Concepts

### Loops
Daily habits.
- Miss a day → streak breaks
- No recovery
- Red stays red

### Sprints
Time-bound goals.
- Partial completion allowed
- Progress matters, perfection doesn’t

### Days
- Complete at least one task → **Showed up**
- Complete nothing → **Missed**
- Days judge presence, not perfection

## What grindin is NOT

- ❌ Not a dopamine machine  
- ❌ Not a motivational quotes app  
- ❌ Not soft

## MVP Status

This project is currently in **MVP development**.
- UI/UX driven
- Built with Swift & SwiftUI
- Not yet released to the App Store

The goal is clarity, not scale.

## Why it exists

To build consistency.
To remove excuses.
To make showing up non-negotiable.
